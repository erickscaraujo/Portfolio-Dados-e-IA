# Monitoramento de Drift de Modelo

Camada de observabilidade para modelos em produção (MLOps).

## Destaques
- PSI por quantis com zonas oficiais (estável/alerta/crítico)
- Teste KS como segunda evidência estatística
- Score médio e taxa de aprovação acompanhados semana a semana
- Regra automática de retreino após N semanas críticas consecutivas
- Painel PNG com as zonas coloridas

## Stack
numpy, scipy, pandas, matplotlib

## Como rodar
```bash
python main.py
```
