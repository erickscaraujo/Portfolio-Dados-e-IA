# Canary Deploy de Modelo

Promoção gradual com prova estatística — como times de ML sérios trocam modelos.

## Destaques
- Champion × Challenger treinados de propósito com qualidade diferente
- Roteamento 90/10 do tráfego; canário acumula amostra mínima antes de decidir
- Comparação de AUC por lote com margem mínima para promover
- Veredito confrontado com a "verdade de mercado" simulada

## Stack
scikit-learn

## Como rodar
```bash
python main.py
```
