# Relatório de Cohort de Retenção

Quando os clientes adquiridos voltam a comprar? Matriz clássica de cohort para BI.

## Destaques
- Cohorts por mês de aquisição com offsets M0..M11
- Lealdade latente por cliente (beta) com decaimento exponencial de recompra
- Heatmap HTML puro com escala de cor e células "futuras" vazias
- Retenção média por offset no console

## Stack
pandas, numpy (HTML gerado manualmente)

## Como rodar
```bash
python main.py   # gera outputs/cohort_retencao.html
```
