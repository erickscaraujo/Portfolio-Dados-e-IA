# Relatório Executivo Mensal

Automação do fechamento mensal por filial com entrega em Excel formatado.

## Destaques
- Consolidação multi-filial com regra de atingimento ajustada (+2% de folga)
- Excel com cabeçalhos congelados, autofiltro e realce de metas não batidas
- Leitura executiva direta no console

## Stack
pandas, numpy, openpyxl

## Como rodar
```bash
python main.py   # gera outputs/relatorio_executivo.xlsx
```
