# DRE Mensal e Margens

Demonstração simplificada de resultados: da receita bruta à margem líquida.

## Destaques
- Estrutura DRE: impostos, CMV, despesas fixas e marketing variável
- Margens bruta/operacional/líquida mês a mês com comparação YoY
- Composição do último mês em barras (estrutura de custos)
- Export CSV pronto para o financeiro

## Stack
pandas, numpy, matplotlib

## Como rodar
```bash
python main.py   # gera outputs/dre_margens.png e outputs/dre_mensal.csv
```
