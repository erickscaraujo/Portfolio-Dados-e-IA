# Ranking de Vendedores — Quota

Leaderboard anual: atingimento, sequências de meses batendo meta e política de prêmios.

## Destaques
- Atingimento médio, melhor mês e streak atual de quota batida
- Pontuação composta (80% atingimento + 20% consistência)
- Simulação da política de premiação (top 3 + regra de mínimo 90%)
- Barras horizontais com linha de 100% (`outputs/ranking_vendedores.png`)

## Stack
pandas, numpy, matplotlib

## Como rodar
```bash
python main.py
```
