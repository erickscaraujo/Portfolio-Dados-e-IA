# Matriz BCG — Carteira de Produtos

Classificação estratégica: estrela, vaca leiteira, interrogação e abacaxi.

## Destaques
- Crescimento YoY × participação relativa de mercado por produto
- Quadrantes com cortes configuráveis (10% de crescimento, share 1.0)
- Bolhas dimensionadas pela receita + receita exposta em cada quadrante
- Recomendações de portfólio por quadrante

## Stack
pandas, numpy, matplotlib

## Como rodar
```bash
python main.py
```
