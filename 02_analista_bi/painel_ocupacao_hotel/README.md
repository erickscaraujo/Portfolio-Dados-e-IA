# Painel de Ocupação — Hotel

Ocupação, ADR, RevPAR, cancelamentos e mix de canais.

## Destaques
- 18 meses com alta temporada embutida (dez–fev e julho)
- ADR (tarifa média) e RevPAR (receita por quarto disponível)
- Cancelamento por canal: OTA cancela mais que direto
- Painel ocupação + barras ADR/RevPAR

## Stack
R base (sem pacotes externos)

## Como rodar
```r
Rscript main.R   # gera outputs/hotel_ocupacao.png + hotel_resumo.csv
```
