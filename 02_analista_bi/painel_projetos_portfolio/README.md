# Painel de Projetos — Portfólio PMO

Conclusão × orçamento com semáforo de risco por projeto.

## Destaques
- 14 projetos: % conclusão, orçado × realizado, dias para o prazo
- Score de risco composto (estouro de custo + atraso + conclusão defasada)
- Semáforo verde/amarelo/vermelho com regras explícitas
- Quadrante gasto × entrega e tabela ordenada pelo risco

## Stack
R base

## Como rodar
```r
Rscript main.R   # gera outputs/portfolio_projetos.png + portfolio_riscos.csv
```
