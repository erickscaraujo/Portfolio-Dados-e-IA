# Concentração de Receita — Gini e HHI

Quanto a receita depende de poucos clientes? Curva de Lorenz, Gini e HHI.

## Destaques
- Top 1/5/10% de clientes: participação na receita
- Coeficiente de Gini implementado com integração trapezoidal
- HHI (índice Herfindahl) com leitura de risco antitruste/concentração
- Alerta automático quando um cliente passa de 10% da receita

## Stack
pandas, numpy, matplotlib

## Como rodar
```bash
python main.py   # gera outputs/lorenz_concentracao.png
```
