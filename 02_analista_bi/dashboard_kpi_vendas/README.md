# Dashboard KPI de Vendas

KPIs comerciais consolidados contra meta, entregues como dashboard HTML estático — sem frameworks front-end.

## Destaques
- Faturamento vs meta, ticket médio, pedidos e margem com comparação YoY
- Tabela mensal com progresso em barras SVG inline
- HTML/CSS gerado 100% em Python

## Stack
pandas, numpy (HTML gerado manualmente)

## Como rodar
```bash
python main.py          # gera outputs/dashboard.html
```
Abra o arquivo no navegador.
