# Geração Solar — Performance do Sistema

Geração diária, performance ratio contra a irradiação e impacto de dias nublados.

## Destaques
- 120 dias com sazonalidade e nublados embutidos
- Performance Ratio = geração ÷ (irradiação × capacidade) — o KPI do setor
- Comparação de PR em dias limpos × nublados
- Economia financeira acumulada pela energia gerada

## Stack
R base

## Como rodar
```r
Rscript main.R   # gera outputs/solar_geracao.png
```
