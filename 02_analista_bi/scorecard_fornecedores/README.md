# Scorecard de Fornecedores

Ranking ponderado de desempenho: pontualidade, qualidade, preço e lead time.

## Destaques
- Nota 0–100 com pesos de negócio (35% OTD, 30% qualidade, 20% preço, 15% lead time)
- Classificação A/B/C com cortes claros para gestão de relacionamento
- Métrica composta de preço vs índice de mercado
- Ranking horizontal + CSV para o ERP

## Stack
pandas, numpy, matplotlib

## Como rodar
```bash
python main.py   # gera outputs/scorecard_fornecedores.csv e PNG
```
