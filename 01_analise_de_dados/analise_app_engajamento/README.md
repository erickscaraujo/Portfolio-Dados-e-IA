# Análise de Engajamento — App Mobile

DAU/WAU, stickiness e curvas de retenção por cohort de instalação.

## Destaques
- 90 dias de atividade com aderência latente e decay natural pós-instalação
- Stickiness DAU/WAU como termômetro de hábito
- Retenção média D1/D7/D30 com cohort tracking correto
- Painel DAU × WAU + barras de retenção (`outputs/engajamento_app.png`)

## Stack
pandas, numpy, matplotlib

## Como rodar
```bash
python main.py
```
