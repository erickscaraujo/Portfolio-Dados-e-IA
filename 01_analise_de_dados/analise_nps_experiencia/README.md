# Análise NPS — Experiência do Cliente

NPS com decomposição: evolução mensal, região e drivers de nota.

## Destaques
- Cálculo clássico promotores − detratores com composição completa
- Tendência de melhora ao longo do ano embutida nos dados
- Driver quantificado: tempo de atendimento × nota (correlação e NPS por faixa)
- Três visões em um painel (`outputs/nps_experiencia.png`)

## Stack
pandas, numpy, matplotlib

## Como rodar
```bash
python main.py
```
