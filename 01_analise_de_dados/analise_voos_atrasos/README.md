# Atrasos de Voos — Companhias e Rotas

Pontualidade, atraso médio dos atrasados e cancelamentos por companhia.

## Destaques
- 4 companhias com perfis operacionais distintos
- Pontualidade definida como atraso < 15 min (padrão do setor)
- Pior rota por atraso médio e taxa de cancelamento por empresa
- Histograma da cauda longa + barras comparativas

## Stack
R base

## Como rodar
```r
Rscript main.R   # gera outputs/voos_atrasos.png
```
