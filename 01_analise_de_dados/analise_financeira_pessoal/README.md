# Análise Financeira Pessoal

Fluxo de caixa pessoal de 18 meses com controle de orçamento por categoria.

## Destaques
- Geração realista de lançamentos (parcela fixa + variável por categoria)
- Taxa de poupança mensal vs meta de 20%
- Comparação orçamento × realizado com alertas acima de +5%
- Área empilhada de despesas e relatório markdown

## Stack
pandas, numpy, matplotlib

## Como rodar
```bash
python main.py
```
