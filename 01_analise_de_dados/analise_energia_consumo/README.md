# Análise de Consumo de Energia

Perfil horário de carga e comparação tarifária para três setores ao longo de um ano.

## Destaques
- Curva de carga média por hora com janela de ponta destacada
- Consumo mensal por setor com efeito sazonal do verão (ar-condicionado)
- Simulação tarifa branca × convencional e economia média mensal
- Área empilhada do consumo mensal (`outputs/energia_consumo.png`)

## Stack
pandas, numpy, matplotlib

## Como rodar
```bash
python main.py
```
