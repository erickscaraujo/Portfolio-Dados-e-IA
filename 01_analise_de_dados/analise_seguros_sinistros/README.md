# Análise de Sinistros — Seguros

Sindicalidade da carteira: frequência, severidade e aging de sinistros abertos.

## Destaques
- Loss ratio por produto contra teto técnico de 70%
- Frequência (por mil apólices) × severidade média separados
- Aging de sinistros abertos em buckets 0-30/31-90/90+ dias
- Painel com 3 visões (`outputs/sinistros_seguros.png`)

## Stack
pandas, numpy, matplotlib

## Como rodar
```bash
python main.py
```
