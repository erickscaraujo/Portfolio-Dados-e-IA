# Analise de Vendas — Varejo

EDA completa sobre uma base sintética de 9 mil pedidos (18 meses, 4 lojas, 5 categorias).

## Destaques
- Limpeza e colunas derivadas (receita, custo, margem)
- KPIs executivos: ticket médio, margem, crescimento trimestral e MoM
- Ranking de categorias, desempenho por loja e top produtos
- Relatório `outputs/resumo.md` + 3 gráficos PNG

## Stack
pandas, numpy, matplotlib

## Como rodar
```bash
python main.py
```
