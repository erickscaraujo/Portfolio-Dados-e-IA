# Engenharia de Cardápio — Restaurante

Popularidade × rentabilidade: o que manter, reformular ou tirar do menu.

## Destaques
- Matriz clássica: estrelas, cavalos de batalha, puzzles e cães
- Margem de contribuição por item e mix percentual das vendas
- Recomendação operacional por quadrante (preço, posição no cardápio, remoção)
- Scatter quadrantes com bolha = vendas (`outputs/cardapio_engenharia.png`)

## Stack
pandas, numpy, matplotlib

## Como rodar
```bash
python main.py
```
