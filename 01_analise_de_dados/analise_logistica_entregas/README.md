# Análise Logística de Entregas

Desempenho de entrega de 5 mil embarques entre 3 transportadoras.

## Destaques
- OTD (on-time delivery) por transportadora, região e evolução mensal
- Atraso médio, custo por kg e piora sazonal de fim de ano
- Painel com 3 visões (`outputs/logistica.png`)

## Stack
pandas, numpy, matplotlib

## Como rodar
```bash
python main.py
```
