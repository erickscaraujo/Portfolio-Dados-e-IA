# Diário de Treino — Musculação

Volume por grupo muscular, progressão de carga e recordes pessoais.

## Destaques
- 12 semanas × 4 exercícios com sobrecarga progressiva realista
- Volume total (séries × reps × carga) por semana e por grupo
- Tendência de carga via regressão linear por exercício
- PRs: maior carga atingida e em que semana

## Stack
R base

## Como rodar
```r
Rscript main.R   # gera outputs/musculacao_progresso.png
```
