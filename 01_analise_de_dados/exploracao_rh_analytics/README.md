# Exploração RH Analytics

Investiga os fatores por trás do turnover usando uma base sintética de 1.200 colaboradores.

## Destaques
- Taxa de rotatividade por departamento e faixa de satisfação
- Mediana salarial por cargo e correlação salário × saída
- Painel com 3 visualizações (`outputs/painel_rh.png`)

## Stack
pandas, numpy, matplotlib

## Como rodar
```bash
python main.py
```
