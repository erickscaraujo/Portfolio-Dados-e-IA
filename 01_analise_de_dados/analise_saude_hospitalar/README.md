# Análise Saúde Hospitalar

Indicadores assistenciais de 2,4 mil internações em 4 especialidades.

## Destaques
- Permanência média, P90 de espera e taxa de reinternação em 30 dias
- Ocupação estimada contra a capacidade de leitos
- Relação permanência longa × reinternação embutida nos dados
- Painel boxplot + barras + histograma (`outputs/saude_hospitalar.png`)

## Stack
pandas, numpy, matplotlib

## Como rodar
```bash
python main.py
```
