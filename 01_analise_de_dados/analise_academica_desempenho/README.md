# Análise Acadêmica — Desempenho de Alunos

Notas, frequência e os fatores que realmente explicam aprovação.

## Destaques
- 600 alunos × 4 matérias com dificuldades distintas por disciplina
- Regra composta de aprovação: média ≥ 6 **e** frequência ≥ 75%
- Faixas de horas de estudo vs taxa de aprovação; correlações com a média
- Detecção de alunos reprovados somente por falta

## Stack
pandas, numpy, matplotlib

## Como rodar
```bash
python main.py   # gera outputs/desempenho_academico.png + resumo md
```
