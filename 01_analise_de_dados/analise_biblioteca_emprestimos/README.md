# Análise de Empréstimos — Biblioteca

Sazonalidade mensal, gêneros mais emprestados e inadimplência de devoluções.

## Destaques
- 12 meses de empréstimos com pico em férias escolares embutido
- Top gêneros e tempo médio de posse por categoria
- Atrasos: livros vencidos, leitor recorrente de atraso
- Gráfico de série mensal + barras por gênero

## Stack
R base (sem pacotes externos)

## Como rodar
```r
Rscript main.R   # gera outputs/biblioteca_emprestimos.png
```
