# Chuvas e Clima — Estação Meteorológica

Chuva mensal, dias secos consecutivos (veranico) e amplitude térmica.

## Destaques
- 3 anos de dados diários com estação chuvosa embutida (nov–mar)
- Dias de chuva × volume; maior sequência seca do período
- Amplitude térmica média por mês (mínima × máxima)
- Série diária + barras mensais

## Stack
R base (sem pacotes externos)

## Como rodar
```r
Rscript main.R   # gera outputs/clima_chuvas.png
```
