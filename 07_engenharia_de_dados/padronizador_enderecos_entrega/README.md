# Padronizador de Endereços

Endereços bagunçados → formato único, pronto para deduplicação e entrega.

## Destaques
- Abreviações mapeadas (R./Av./Trav.) e caixa normalizada
- CEP formatado 00000-000 a partir de qualquer variação
- Chave de dedup derivada do endereço padronizado
- Relatório antes × depois com redução de duplicatas visuais

## Stack
R base

## Como rodar
```r
Rscript main.R   # gera outputs/enderecos_padronizados.csv
```
