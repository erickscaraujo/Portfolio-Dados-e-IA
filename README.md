# Portfólio — Dados & IA

Coleção de **127 projetos completos e executáveis** — a maioria em Python (lint com Ruff) e 16 recentes em linguagem R (lint com lintr) — organizados por área de atuação. Cada projeto gera seus próprios dados sintéticos, roda de ponta a ponta e entrega entregáveis reais (relatórios, gráficos, modelos, APIs, data warehouse).

Cada pasta de projeto contém seu próprio `README.md` com objetivo, stack e modo de execução. Os artefatos gerados (PNG, HTML, XLSX, JSON, modelos) ficam em `outputs/`.

## Como rodar

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -r requirements.txt
python main.py                # dentro da pasta do projeto desejado
```

## Qualidade de código

Todo o repositório passa no linter/formatter [Ruff](https://docs.astral.sh/ruff/):

```bash
ruff check .
ruff format --check .
```

A configuração está centralizada no `pyproject.toml`.

## Qualidade de código — R

Os projetos em linguagem R passam no [lintr](https://lintr.r-lib.org/) com a configuração
centralizada no `.lintr` (linha de 120 colunas, complexidade ciclomática ≤ 30):

```bash
Rscript -e "lintr::lint_dir('.')"
```
