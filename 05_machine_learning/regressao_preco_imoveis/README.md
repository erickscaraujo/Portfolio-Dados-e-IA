# Regressão de Preço de Imóveis

Modelo de precificação com interpretação econômica dos coeficientes.

## Destaques
- Sintese realista: área, cômodos, idade, distância ao centro e prêmio por bairro
- Linear Regression vs HistGradientBoosting (MAE/R²)
- Interpretação: coeficientes quando linear vence, permutação quando boosting vence
- Dispersão real × previsto e modelo serializado

## Stack
pandas, numpy, scikit-learn, joblib, matplotlib

## Como rodar
```bash
python main.py
```
