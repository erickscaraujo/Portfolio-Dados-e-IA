# Importância de Features — Métodos em Conflito

Coeficiente, permutação e drop-column discordam? Cada um responde uma pergunta diferente.

## Destaques
- Três métodos no mesmo modelo: nativo, permutação e drop-column (retreino)
- Feature correlacionada/redundante usada para expor o viés de cada método
- Tabela ranqueada lado a lado + divergências comentadas
- Recomendação de qual método usar para qual decisão

## Stack
pandas, numpy, scikit-learn

## Como rodar
```bash
python main.py
```
