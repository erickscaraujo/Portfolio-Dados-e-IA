# Calibração de Probabilidades

A probabilidade prevista significa o que diz? Diagrama de confiabilidade e Brier score.

## Destaques
- Modelo descalibrado × Platt (sigmoid) × isotônico via `CalibratedClassifierCV`
- Brier score e log loss comparados
- Diagrama de confiabilidade por faixas de probabilidade
- Tabela predito × observado por bin para leitura executiva

## Stack
numpy, scikit-learn, matplotlib

## Como rodar
```bash
python main.py
```
