# Detecção de Anomalias em Transações

Antifraude não supervisionado com avaliação contra fraudes plantadas.

## Destaques
- Regra IQR vs IsolationForest (contamination calibrada à taxa real)
- Hora codificada de forma cíclica (sin/cos) — madrugada "perto" da noite
- Precisão/recall/F1 por método e top alertas para investigação
- Dispersão log-scale valor × hora com alertas destacados

## Stack
pandas, numpy, scikit-learn, matplotlib
