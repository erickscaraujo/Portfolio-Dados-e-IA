# Classificador k-NN — Qualidade de Vinhos

k-vizinhos mais próximos implementado do zero, com escolha do k.

## Destaques
- Distância euclidiana e votação majoritária escritos na mão
- Padronização z-score (obrigatória no k-NN) calculada só com estatísticas de treino
- Grade k = 1..15 por acurácia em validação; teste final limpo
- Matriz de confusão + erro por classe

## Stack
R base (sem pacotes externos)

## Como rodar
```r
Rscript main.R
```
