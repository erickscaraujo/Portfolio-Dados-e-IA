# Modelo de Uplift — Marketing

Quem compra *porque* recebeu a campanha? T-learner sobre experimento randomizado.

## Destaques
- Segmentos latentes realistas: persuadidos, sempre-compram e "cães dorminhocos" (efeito negativo)
- Dois modelos (tratados × controle) e uplift = diferença de probabilidades
- Conversão incremental observada por decil de score
- Curva de ganho acumulado + recomendação de corte nos 3 melhores decis

## Stack
pandas, numpy, scikit-learn, matplotlib

## Como rodar
```bash
python main.py
```
