# Elasticidade Preço-Demanda

Quanto a demanda responde ao preço — e qual preço maximiza a receita.

## Destaques
- Regressão log-log: coeficiente = elasticidade-preço da demanda
- Interpretação econômica automática (elástico × inelástico)
- Otimização de receita sobre a curva estimada (grade de preços)
- Curva de demanda e curva de receita lado a lado

## Stack
numpy, scikit-learn, matplotlib

## Como rodar
```bash
python main.py
```
