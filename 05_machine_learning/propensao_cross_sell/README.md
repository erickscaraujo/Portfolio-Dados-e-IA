# Propensão de Cross-Sell

Quem tem maior chance de contratar o próximo produto — e a lista priorizada.

## Destaques
- Afinidades latentes entre produtos (quem tem cartão+investimento quer seguro)
- GradientBoosting para P(contratar seguro) em quem ainda não tem
- Ranking com Precision@10% e lift sobre o aleatório
- Curva de ganho acumulado (`outputs/cross_sell_ganho.png`)

## Stack
pandas, numpy, scikit-learn, matplotlib

## Como rodar
```bash
python main.py
```
