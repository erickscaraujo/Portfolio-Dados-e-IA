# Teste t Pareado — Avaliação de Treinamento

Antes × depois dos mesmos funcionários: t pareado, Wilcoxon e Cohen's d.

## Destaques
- Scores de 90 funcionários antes/depois de um curso
- Normalidade das DIFERENÇAS (Shapiro) decide entre t pareado e Wilcoxon
- Cohen's d para amostras pareadas + IC via bootstrap
- Veredito combinando p-valor, tamanho do efeito e ganho médio

## Stack
R base (sem pacotes externos)

## Como rodar
```r
Rscript main.R
```
