# Simulação Monte Carlo — Projeção de Receita

10 mil cenários futuros em vez de um número único.

## Destaques
- Crescimento, sazonalidade e sobrevivência de clientes como distribuições
- 12 meses × 10.000 trajetórias vetorizadas em numpy
- P5/P50/P95 por mês + probabilidade de bater a meta anual
- Fan chart da projeção (`outputs/monte_carlo_receita.png`)

## Stack
numpy, matplotlib

## Como rodar
```bash
python main.py
```
