# Teste Qui-Quadrado — Associação entre Categorias

Independência entre variáveis categóricas com Cramér's V.

## Destaques
- Tabela de contingência observada × esperada
- `chi2_contingency` com correção de Yates quando aplicável
- Cramér's V para tamanho do efeito (não só p-valor)
- Dois cenários em contraste: associação plantada × independência real

## Stack
pandas, numpy, scipy

## Como rodar
```bash
python main.py
```
