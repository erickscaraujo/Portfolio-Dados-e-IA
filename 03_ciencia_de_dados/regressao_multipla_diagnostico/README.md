# Regressão Múltipla com Diagnóstico

`lm()` completo: summary, resíduos, R² ajustado e checagem visual dos pressupostos.

## Destaques
- Modelo de salário por experiência/educação/cargo com dados sintéticos
- `summary(lm)` com significância; interpretação dos coeficientes
- 4 gráficos de diagnóstico (resíduos × ajustados, Q-Q, scale-location, alavancagem)
- Comparação de modelos aninhada via ANOVA

## Stack
R base (sem pacotes externos)

## Como rodar
```r
Rscript main.R   # gera outputs/regressao_diagnostico.png
```
