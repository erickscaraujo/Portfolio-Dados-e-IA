# Teste de Hipóteses — Campanhas de Marketing

Comparação estatística de 4 criativos na receita por usuário.

## Destaques
- Shapiro (normalidade), Levene (homocedasticidade) antes da ANOVA
- ANOVA um fator + post-hoc Tukey HSD par a par
- Cohen's d para tamanho do efeito do vencedor vs controle
- Veredito com lift e impacto financeiro estimado

## Stack
numpy, scipy

## Como rodar
```bash
python main.py
```
