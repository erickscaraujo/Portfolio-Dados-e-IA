# Odds Ratio — Interpretando a Regressão Logística

Do coeficiente à frase que o negócio entende.

## Destaques
- Coeficientes convertidos em odds ratios com intervalo via erro-padrão
- Interpretação por unidade e por incremento de negócio (ex.: +0,10 de dívida/renda)
- Efeito marginal na média: quantos p.p. muda a probabilidade
- Comparação lado a lado de dois perfis de cliente

## Stack
pandas, numpy, scikit-learn

python main.py
