# Teste Mann-Whitney — Diferença Salarial

Estatística não-paramétrica para comparar distribuições assimétricas.

## Destaques
- Justificativa do teste pela assimetria (skew) das distribuições
- Mann-Whitney U + tamanho de efeito rank-biserial
- IC 95% da diferença de medianas via bootstrap (10 mil reamostragens)
- Decisão combinando p-valor e intervalo de confiança

## Stack
numpy, scipy

## Como rodar
```bash
python main.py
```
