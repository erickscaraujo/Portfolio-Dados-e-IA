# Cálculo de Amostra para Pesquisas

Tamanho de amostra, margem de erro e alocação estratificada — a matemática antes do campo.

## Destaques
- Fórmula para proporções com correção de população finita
- Curva margem × tamanho de amostra
- Simulação end-to-end: população real → amostra estratificada proporcional → estimativa com IC
- Checagem: a taxa verdadeira cai dentro do intervalo?

## Stack
numpy, matplotlib

## Como rodar
```bash
python main.py
```
