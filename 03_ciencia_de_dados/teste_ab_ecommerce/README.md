# Teste A/B — E-commerce

Framework completo de experimentação aplicado a um redesign de checkout.

## Destaques
- Z-teste agrupado para duas proporções implementado do zero
- Intervalos de confiança, poder estatístico e cálculo de amostra mínima (MDE)
- Conclusão com recomendação de negócio e impacto financeiro estimado

## Stack
numpy, scipy

## Como rodar
```bash
python main.py
```
