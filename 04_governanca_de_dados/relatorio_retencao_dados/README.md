# Retenção de Dados — Política de Descarte

O que já venceu o prazo legal de retenção e pode ser apagado com segurança.

## Destaques
- Prazos por categoria (cada dado vive o que a lei/política manda)
- Varredura das tabelas marcando registros vencidos vs ainda retidos
- Agenda de descarte consolidada + volume liberado por tabela
- CSV da fila de exclusão para o job de limpeza

## Stack
R base

## Como rodar
```r
Rscript main.R   # gera outputs/fila_descarte.csv
```
