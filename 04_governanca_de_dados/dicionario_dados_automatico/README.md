# Dicionário de Dados Automático

Documentação viva gerada a partir dos próprios dados.

## Destaques
- Tipo, % de nulos, estatísticas/exemplos por coluna — sem trabalho manual
- Detecção de PII por nome de coluna e conteúdo (e-mail, CPF)
- Glossário manual da equipe tem prioridade sobre o texto inferido
- Saída em Markdown pronta para wiki/PR

## Stack
pandas, stdlib

## Como rodar
```bash
python main.py   # gera outputs/dicionario_dados.md
```
